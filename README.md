# TrekTour

>TrekTour is an online trek management system that uses Role-Based Access Control to ease the process of managing 
treks.



### Steps to Runs

1. Create a virtual environment
    ```sh
    python -m venv venv
    ```
2. Activate the virtual environment
    ```sh
    .\venv\Scripts\activate    
    ```
3. Install the Prerequisites
    ```sh
    pip install -r requirements.txt
    ```
4. Run the Application
    ```sh
    flask run
    ```
